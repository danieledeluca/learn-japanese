# Learn Japanese

An interactive web app for learning Hiragana and Katakana through matching games. Built with Nuxt 4, Nuxt UI, and Pinia.

## Features

- **Two alphabets** — practice Hiragana or Katakana independently
- **Matching gameplay** — pair Japanese characters with their romaji translations
- **Configurable rounds** — choose 15, 30, 50, or all 71 letters per game
- **Instant feedback** — correct matches pulse green, wrong ones shake red
- **Results screen** — tracks errors, time, and precision percentage
- **Progress saved** — game state persists in localStorage so you can pick up where you left off
